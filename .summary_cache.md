## Goal
Implement full CI/CD pipeline, fix all critical bugs, replace cage→labwc for working on-screen keyboard, harden Firefox policies, optimize build performance, and fix CI lint/format errors.

## Constraints & Preferences
- Runners: `ubuntu-latest` (x86) — cross-build aarch64
- Image-gen needs `binfmt`/qemu (see root `Dockerfile` amd64 path)
- `cargo-zigbuild` for native macOS dev cross-compile (skips Docker)
- No CDN assets in frontend (setup runs offline)
- Pi 3 is target HW (weak CPU, ~1GB RAM, SD storage)
- All changes tracked in `Improvements.md` with 🟢 markers
- Debian bookworm repos only — `wvkbd-mobintl` not available (trixie+), use `wvkbd` base package
- `squeekboard` has unresolvable deps in bookworm arm64 → swapped for `wvkbd`

## Key Decisions
- **cage→labwc swap**: necessary for OSK to render above fullscreen Firefox (cage doesn't composite wlr-layer-shell overlays above xdg fullscreen surfaces)
- **squeekboard→wvkbd**: squeekboard deps unresolvable in bookworm arm64. `wvkbd --show` stays always-visible (acceptable for kiosk; user never taps to summon keyboard). `wvkbd-mobintl` is trixie-only, use base `wvkbd` package.
- **sd_notify native**: `UnixDatagram` to `$NOTIFY_SOCKET` avoids `libsystemd-dev` compile dependency (crate-free). Works on any Linux target.
- **`--pull never` removed** from `docker compose build` — flag incompatible with older Docker Compose
- **Removed `cargo-deny` advisories job**: config API churn across v0.14→v0.16 made it unreliable in CI; `cargo-audit` covers the same need with stable cli
- **Docker layer caching via GHA cache** rather than `/var/lib/docker` — works with buildkit
- **Cargo-chef multi-stage**: `target/` is in the Docker image (not on bind mount); `docker create` + `docker cp` extracts binary from scratch stage. Compatible with CI and dev (where `cargo-zigbuild` is the fast path anyway)
- **Autostart uses `kiosk-launch.sh`** instead of raw Firefox launch — preserves WiFi/internet check branching
- **Cross-compiler install for cargo-deny**: install `gcc-aarch64-linux-gnu` and use explicit `--target` rather than removing cargo-deny, since license/bans checks add value
